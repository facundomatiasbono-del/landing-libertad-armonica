# ARMONÍA Y ACORDES · VOL. 1

Un recorrido práctico para empezar a **entender la armonía directamente sobre la guitarra.**

Vas a aprender a:

→ Entender cómo se construyen y relacionan los acordes de una tonalidad.  
→ Mover un mismo acorde por distintas zonas del mástil.  
→ Usar inversiones y extensiones para ampliar tu vocabulario.  
→ Encontrar nuevas posibilidades para una misma progresión.  
→ Sustituir acordes entendiendo qué función cumplen.  
→ Transportar y tocar en diferentes tonalidades.  
→ Empezar a modular conscientemente.

### No se trata de aprender más acordes.
